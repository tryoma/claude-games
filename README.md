# あそびの棚

ブラウザでそのまま遊べる小さなゲーム集です。GitHub Pages で公開しています。

## 構成

```
index.html        一覧ページ（games.js を読んで棚を描きます）
games.js          ゲームの一覧。ここに書いた順に並びます
games/<id>.html   ゲーム本体（1ファイルで完結）
thumbs/<id>.svg   一覧に出すサムネイル（320×180）
```

## ゲームを追加する

1. ゲームを `games/<id>.html` として置く（`<id>` は英小文字。例：`games/puzzle.html`）
2. ゲームの画面の左上あたりに、一覧へ戻るリンクを入れる
   ```html
   <a href="../">← あそびの棚</a>
   ```
3. サムネイルを `thumbs/<id>.svg` として置く（横320×縦180）
4. `games.js` の配列に1件追加する
   ```js
   {
     "id": "puzzle",
     "title": "ゲームの名前",
     "description": "一覧に出す1〜2文の説明。",
     "tags": ["パズル", "1人用"]
   }
   ```

棚は件数に合わせて自動で並べ替わります（横長の箱と通常の箱を組み合わせて、空きが出ないようにしています）。

## 記録について

各ゲームの自己ベストは、遊んだ人のブラウザ（localStorage）に保存されます。サーバーには何も送りません。
